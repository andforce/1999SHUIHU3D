# 1999 小浣熊水浒收藏图鉴

本地静态图鉴，将 108 张卡片与对应的人物五视图、武器图和坐骑图关联展示。

## 本地运行

```bash
./run-dev.sh
```

首次运行会自动安装 npm 依赖并生成卡片缩略图，随后访问 <http://127.0.0.1:5173>。

## 常用命令

```bash
npm run assets:check  # 校验素材数量
npm run test          # 运行自动化测试
npm run build         # 生成静态构建产物
npm run preview       # 预览构建产物
```

源图片不会被修改。生成的目录、缩略图和 `dist/` 构建产物均可重新生成。
