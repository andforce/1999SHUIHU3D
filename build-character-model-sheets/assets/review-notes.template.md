# 审核记录

## 身份一致性

- [ ] 脸型、五官、发型和胡须一致
- [ ] 年龄感、体型和头身比一致

## 服装一致性

- [ ] 衣物层级和闭合方向一致
- [ ] 左右不对称设计没有翻转
- [ ] 非对称特征始终连接角色自身同一侧和同一三维锚点
- [ ] 远侧特征正确遮挡，没有为了可见性被移动到近侧
- [ ] 配色、材质、纹样和甲片一致

## 实体一致性

- [ ] 武器形制、长度、握持点和收纳方式一致或不适用
- [ ] 坐骑、宠物的比例和装备一致或不适用

## 图像质量

- [ ] 六个视角完整、顺序正确且基线统一
- [ ] 头部放大图按正面、背面、左侧面、右侧面四视图完整排列
- [ ] 左右侧面来自角色不同侧，没有复制或水平翻转
- [ ] 四张头部的脸型、颅骨、五官、发际线、发型、胡须、耳朵、头饰锚点、表情和裁切一致
- [ ] 纯背面完整展示后脑发型和头饰连接结构
- [ ] 顺序为基于左面逆时针转45度、左面、正面、背面、右面、基于右面顺时针转45度
- [ ] 左面/右面为相反的纯侧视；正面/背面为相反的纯正视/纯背视
- [ ] 第一列只基于第二列左面逆时针转45度；第六列只基于第五列右面顺时针转45度
- [ ] 第一列/第六列的近侧脸颊、耳朵、肩膀、胸甲透视和远侧遮挡相反
- [ ] 两列均为全身统一旋转，没有退化成纯侧面或正面、复制另一列或只转头
- [ ] 正面/背面、左面/右面、两个相对45度视图三组视角的非对称锚点一致
- [ ] 无多余肢体、重复物件、融合结构和文字乱码
- [ ] 推断部分已记录，未知部分没有伪装成事实

## 固定画风一致性

- [ ] 深黑或深褐色手绘墨线清楚，外轮廓有粗细变化，内部结构线没有消失
- [ ] 基色色块清楚，每种主要材质约有 2–4 档结构明暗，并保留克制的刷痕、排线或方向性纹理
- [ ] 六个全身视角和四个头部视角的线宽、综合色阶、纹理密度和光源一致
- [ ] 人物保留原卡年龄、骨相和体型差异，没有幼态化、现代动漫化或批量同脸
- [ ] 没有漂移为纯赛璐璐、无描线半厚涂、现代手游宣传画、照片写实、3D/PBR 或矢量图
- [ ] 没有继承原卡叙事背景、场景特效、卡框、文字、扫描噪点或旧印刷损伤

## 返修说明

## 原画姿态版六视图（可选，不适用时留空）

- [ ] 独立输出已记录，默认 `character-turnaround.png` 未被覆盖或改名
- [ ] 原画作为姿态、手势、服装动态和实体关系的最高视觉依据
- [ ] 六列为同一个冻结动作，不是逐列重新摆出的相似动作
- [ ] 头、胸腔、骨盆、四肢、手指、衣物动态和实体在每列共享同一偏航角
- [ ] 武器/道具数量、抓握手、抓握点、长度和身体相对路径一致或不适用
- [ ] 骑乘、鞍具、缰绳、宠物互动和其他接触关系一致或不适用
- [ ] 场景元素已排除，除非用户明确要求其作为角色效果或可建模实体
- [ ] 抬起的手、衣摆、武器端点、坐骑和宠物无裁切，相邻列无重叠
- [ ] `generation.variants` 的状态、输出和六视图顺序与实际文件一致
