# 图像生成提示模板

先从 `character-spec.json` 提取具体设计，替换模板中的方括号。不要把模板原样提交，也不要要求图像模型生成可读说明文字。

小浣熊水浒卡项目在组装下面任何人物或实体模板前，必须先读取 [style-1999-shuihu-cards.md](style-1999-shuihu-cards.md)，把“固定正向提示段落”和“固定禁止漂移段落”完整加入实际生成提示。用户明确指定另一画风时才替换，并把覆盖记录进 `generation.style_profile`。局部返修则要求保持已批准画风不变，不重新解释画风。

## 人物六视图与头部放大视图

```text
以所附角色原画为唯一主要角色设计依据，为同一个角色制作专业动画/游戏人物设定六视图。保持原画中的脸型、五官、发型、胡须、体型、服装层级、颜色、材质、纹样、盔甲和配件完全可识别且跨视角一致。只继承角色设计和固定画风，不继承原卡叙事背景、场景光效、印刷老化或卡面文字。

画面从左到右严格排列：基于左面逆时针转45度、左面、正面、背面、右面、基于右面顺时针转45度。六个人物采用相同头身比、相同高度、相同脚底基线和自然中立站姿，双臂略离开身体以展示服装结构。完整全身，不裁切。第二列必须是纯左面，第三列必须是纯正面，第四列必须是纯背面，第五列必须是纯右面。不要把第一列或第六列改写成独立角度编号，不要改变列顺序。

在同一设定表的独立清晰区域增加一组等比例头肩裁切的头部放大图，从左到右严格排列：正面、背面、左侧面、右侧面。保持同一脸型、颅骨体积、五官比例、发际线、发型、胡须、耳朵、头饰锚点、颈部尺度、中立表情、光照和裁切范围。左侧面与右侧面必须来自角色不同侧，不得复制或水平翻转。纯背面必须完整展示后脑发型和头饰连接结构；未由原图确认的后脑细节只能采用已记录的克制推断。

【两个相对45度视角——硬性约束】
第一列不是独立猜测：只以第二列左面为基准，保持左面已经确定的脸部侧影、服装层级、装备连接和身体结构，把同一个完整人物绕竖直轴逆时针旋转45度。头、胸腔、骨盆、膝盖和双脚必须同步旋转；不得只转头，也不得退化成左面、右面或正面。

第六列也不是独立猜测：只以第五列右面为基准，保持右面已经确定的脸部侧影、服装层级、装备连接和身体结构，把同一个完整人物绕竖直轴顺时针旋转45度。头、胸腔、骨盆、膝盖和双脚必须同步旋转；不得只转头，也不得退化成右面、左面或正面。

第一列和第六列必须来自相反的侧面基准，呈现相反的角色近侧、近侧脸颊/耳朵/肩膀、胸甲透视和远侧肢体遮挡。不得复制、复用或水平翻转另一列。若两列近侧相同、轮廓近似重复，或任一列与纯侧面或正面近似相同，结果即为失败，必须重绘错误列。

必须保留：[must_preserve]
原图可确认：[confirmed]
结构性推断：[inferred]
保持克制或留作简单结构：[unknown]
非对称三维锚点：[asymmetric_anchors]

【非对称结构锚点锁定——硬性约束】
把每个非对称特征永久固定在 `anatomical_side` 指定的角色自身侧和 `attachment_point` 指定的三维连接点，并保持 `local_orientation`、数量、间距和展开形状不变。旋转时只改变观察角度或整个人物的朝向；不得将特征重新连接到另一侧，不得左右交换、镜像复制、改变连接点，也不得为了让它更明显而移到靠近镜头的一侧。

允许非对称特征因透视投影改变画面中的左右位置，但绝不允许改变它在角色身体上的解剖侧。严格遵守 `visibility_by_view` 和真实三维遮挡：远侧特征应被头部、身体、帽冠或服装部分遮挡，只显示从真实位置能够看到的部分。当完整可见性与固定位置冲突时，优先保持固定锚点和正确遮挡。

角色自身左侧特征通常在“基于左面逆时针转45度”和“左面”为近侧，在“右面”和“基于右面顺时针转45度”为远侧；角色自身右侧特征反之。用正面/背面、左面/右面、两个相对45度视图三组视角交叉检查，确保每个特征始终连接同一解剖侧，不发生换边。

使用干净浅色中性背景、均匀工作室光线和清晰轮廓。不要动作姿势、场景、标题、标签、水印、文字、额外人物、重复武器或多余肢体。
```

## 原画姿态版六视图（可选、独立输出）

只在用户明确要求保留原画动作、服装动态或实体关系时使用。生成前先填写 `generation.variants`，并删除模板中与该角色不适用的武器、坐骑或宠物分支。不得把方括号原样提交。

```text
以所附角色原画为姿态、手势、服装动态和实体关系的最高视觉依据，为同一个角色制作一张独立的原画姿态版专业六视图。现有中立六视图只用于补充原图不可见的侧面与背面结构，已确认头部表只用于锁定身份、头饰和头颈比例；任何参考冲突都以原画可见事实为准。不要覆盖或改写现有中立六视图。

【冻结三维组合体】
把原画中的人物和所有持续连接的设计冻结为同一个三维组合体：
- 姿态与手势：[source_pose_and_gesture]
- 头部、视线、胸腔、骨盆、重心和腿部前后关系：[body_orientation_and_balance]
- 服装、头发、披帛、衣摆、尾巴或翅膀的动态轮廓与根部连接：[costume_motion]
- 武器或道具的数量、抓握手、抓握点、长度、身体相对路径和端点：[weapon_or_prop_relation]
- 坐骑、鞍具、缰绳、腿部夹持和骑乘接触：[mount_relation]
- 宠物的位置、尺度、朝向、遮挡和人物接触点：[pet_relation]

六列必须是这一个冻结组合体从六个观察方向看到的结果。整个人物、四肢、手指、衣物动态、武器/道具、坐骑、宠物和所有接触点共同绕竖直轴旋转；不得逐列重新摆动作、换手、改变腿部前后关系、改变握持点、重算风向、移动坐骑/宠物或让实体漂离连接点。表情变化不能代替视角变化。

画面从左到右严格排列：
1. 只以第二列左面为基准，把完整冻结组合体绕竖直轴逆时针旋转45度；
2. 角色自身纯左面；
3. 纯正面，最接近原画可见动作关系；
4. 同一冻结组合体的纯背面；
5. 角色自身纯右面；
6. 只以第五列右面为基准，把完整冻结组合体绕竖直轴顺时针旋转45度。

第一列与第六列必须来自相反侧面基准，呈现相反的近侧脸颊、肩膀、手臂、髋、腿、衣物透视、实体投影和远侧遮挡；不得复制、复用或水平翻转。每列内部的头、胸腔、骨盆、膝、脚、抬起的肢体、衣物动态和实体必须共享同一偏航角。

保持原画中的身份、脸型、体型、发型、胡须、服装层级、颜色、材质、纹样、盔甲和配件，并在六列中保持固定画风的描线、综合色阶、纹理密度和光源完全一致；原图未展示的背面结构只采用规格中已记录的克制推断。一个连续武器或道具始终保持为同一件物体，不得断裂、复制、变形为另一类别或改变抓握关系。没有证据的坐骑、宠物或附件不得添加。

原画中的雷电、岩石、烟雾、云层、题字牌、画框、地面文字和叙事背景默认排除；只有规格确认属于角色设计、附着效果或可建模实体的内容才保留。

使用非常宽的干净浅色中性横向画布和均匀工作室光线。六套冻结组合体同尺度、同地面基准、均匀分栏。完整展示所有手指、脚、衣摆、武器端点、坐骑和宠物；动作轮廓过宽时缩小六列整体尺度并增加留白，不得裁切或让相邻列重叠。

不要标题、标签、编号、水印、边框、额外人物、多余肢体、重复实体、融合结构、错误手指、逐列变化的动作、随机改变的衣物飘向或文字乱码。
```

## 武器设定表

```text
以所附角色原画及已批准人物设定表为依据，制作该角色的[武器名称]独立设计表。准确保持轮廓、配色、材料、纹样、握持位置以及与人物的比例。

展示：完整主视图、反面、最薄侧面、关键局部、握持状态、收纳或连接状态，以及人物比例剪影。若原图未展示背面或内部结构，采用最克制的结构性补全，不添加无依据装饰。

干净浅色中性背景，均匀光线，所有视图尺度逻辑一致。不要场景、动作特效、标题、标签、水印、文字、重复部件或融合结构。
```

## 坐骑或宠物设定表

```text
以所附原画及已批准人物设定表为依据，为同一只[坐骑/宠物名称]制作专业设定表。保持物种、头部、体型、毛色或鳞色、鬃毛、尾巴、花纹、装备和性格特征跨视角一致。

从左到右严格展示[基于左面逆时针转45度、左面、正面、背面、右面、基于右面顺时针转45度]。第一列只以第二列左面为基准逆时针旋转45度；第六列只以第五列右面为基准顺时针旋转45度。两列必须来自不同侧面基准，不得相同、退化成纯侧面或正面，也不得由水平翻转产生。加入与主人并排的准确比例；坐骑还要展示自然骑乘位置与鞍具、缰绳或甲具关系。完整身体，不裁切。

干净浅色中性背景和均匀光线。不要场景、标题、标签、水印、文字、额外动物、多余肢体或无依据装饰。
```

## 局部返修

```text
编辑已附设定图，仅修改：[明确区域和问题]。
改为：[目标结构]。
保持脸、体型、发型、其他服装层级、配色、纹样、装备位置、视角排列、人物尺度、背景、已批准的描线粗细、综合色阶、阴影档数、手绘纹理密度和所有未点名区域完全不变。不得在返修中漂移为另一种渲染风格。
```

## 重复相对视角返修

第一列与第六列相同、过于相似，或其中一列退化成纯侧面或正面时，使用此模板；只保留与错误列对应的分支，不把方括号原样提交。

```text
编辑已附六视图，仅重绘第[一/六]列的[基于左面逆时针转45度/基于右面顺时针转45度]视图；其他五列、画布、间距和背景逐像素级保持不变。

如果修复第一列：只以第二列左面为基准，把同一个完整人物绕竖直轴逆时针旋转45度。保持第二列的身份、结构和非对称三维锚点；头、胸腔、骨盆、膝盖和双脚同步旋转。不得退化成左面、右面或正面，不得复用第六列。

如果修复第六列：只以第五列右面为基准，把同一个完整人物绕竖直轴顺时针旋转45度。保持第五列的身份、结构和非对称三维锚点；头、胸腔、骨盆、膝盖和双脚同步旋转。不得退化成右面、左面或正面，不得复用或水平翻转第一列。

保持同一人物的脸型、体型、服装、配色、材质、非对称三维锚点和真实遮挡。验收条件：第一列与第六列来自相反侧面基准，近侧肩膀相反、胸甲透视相反、远侧遮挡相反，且每列内部的头、胸腔、骨盆和双脚处于同一旋转角。
```

## 非对称特征局部返修

```text
仅修复[视图名称]中的[非对称特征]。该特征必须固定在角色自身的[左侧/右侧][具体连接点]，保持与已批准左面、正面、背面和右面相同的三维锚点、局部朝向、数量、间距和展开形状。

当前视图中该特征位于[近侧/远侧]；按真实空间关系表现遮挡。不得把它移动到角色另一侧，不得镜像、复制，也不得为了完整展示而移到靠近镜头的一侧。只修改该特征的连接位置和遮挡关系，其余所有内容完全不变。
```
