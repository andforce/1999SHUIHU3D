# 1999–2000 年小浣熊水浒卡画风档案

## 适用范围

本档案是该 Skill 的默认画风，标识为 `xiaohuanxiong-shuihu-1999-2000-hand-painted-card`。它用于把 1999–2000 年小浣熊水浒人物卡重建为角色设定图。用户明确指定另一种画风时，以用户要求为准，并在 `generation.style_profile` 中记录覆盖原因。

该画风来自整套正面卡图的共同视觉语言，而不是照搬某一张卡的场景、特效、印刷老化或个别画师偏差。它不是纯赛璐璐，也不是半厚涂、照片写实或三维渲染；准确定位是：

> 1999–2000 年中国水浒英雄收藏卡式二维手绘商业插画，以墨线轮廓和综合色块为骨架，结合马克笔、水彩/水粉、喷笔式柔和过渡与局部排线。

## 固定视觉规则

### 描线

- 使用深黑或深褐色墨线，外轮廓明显，粗细随结构和受力变化；内轮廓较细，但仍清楚描述五官、肌肉、衣褶、甲片和连接关系。
- 线条允许轻微手绘起伏和收笔，不做无菌、等粗、完全光滑的矢量线。
- 在缩略图尺度下仍能一眼读出人物剪影、脸部方向和服装层级。

### 上色与明暗

- 使用高饱和但非荧光的综合色彩，常见红、金、青、绿、蓝、紫形成鲜明冷暖对比；保持每个角色原卡的主辅色关系。
- 以清楚的基色色块组织造型，在每种主要材质上使用约 2–4 档可辨认的结构阴影和高光。
- 硬边色块负责转折，局部允许马克笔、水彩/水粉和喷笔式的柔和过渡；可用短排线、干笔和少量颗粒表现皮肤、布料、毛发和金属，但不得覆盖轮廓或把画面做成无边界厚涂。
- 亮部可见带方向的手绘高光笔触；暗部使用有综合色彩的深色，不统一压成纯黑。

### 人物与材质

- 保留原卡人物各自的年龄、脸型、体型和夸张程度；成年英雄采用有棱角的漫画式五官和扎实人体结构，不把所有角色美型化成同一张现代动漫脸。
- 女性角色保持原卡的成年古典武侠人物气质，不转成幼态、萌系或现代手游网红脸。
- 皮肤以暖赭、桃色或棕色基调配红褐阴影和有限高光；不得出现照片级毛孔、蜡质皮肤或三维次表面散射。
- 布料以大块褶皱色面加少量刷痕表现；金属以冷暖灰色面、清楚边缘和手绘白色高光表现；皮革、木材、毛发保留简洁的方向性纹理。
- 所有视角使用同一描线粗细逻辑、综合色阶、纹理密度和统一光源，不允许正面像卡画、背面像三维概念图。

### 设定表呈现

- 只继承原卡的人物设计、配色和人物绘制语言；移除叙事背景、光环、雷电、火焰、水浪、速度线、花瓣、烟雾、题字、印刷边框等场景化元素，除非它们已被确认为角色实体或附着设计。
- 使用偏暖白或很浅的中性灰背景、稳定的上前方柔和光源和极弱的落地接触阴影。背景不得影响角色固有色判断。
- 不模拟旧卡扫描噪点、网点、纸张泛黄、折痕、压缩伪影或套色误差。要保留的是当年的手绘语言，不是物理老化。

## 固定正向提示段落

生成任何人物、武器、坐骑或宠物设定图时，把下面一段完整加入提示；用户明确覆盖画风时才替换：

```text
画风固定为1999–2000年中国水浒英雄收藏卡式二维手绘商业插画。使用深黑或深褐色、粗细有变化且略带手绘起伏的墨线：外轮廓醒目，内部结构线清楚。保留原卡高饱和但非荧光的综合色彩和鲜明冷暖对比，以清晰基色色块塑造造型，每种主要材质使用约2至4档可辨认的结构阴影与高光；硬边色块为主，局部结合马克笔、水彩/水粉、喷笔式柔和过渡、短排线和干笔纹理。人物保持成年英雄漫画感、棱角明确的五官和扎实人体结构；皮肤、布料、金属、皮革、木材和毛发都以简洁的方向性手绘笔触区分。整体必须保持清楚二维轮廓、纸本手绘质感和复古商业卡画气质，但画面本身干净高清，不模拟旧印刷损伤。所有视角使用完全一致的描线、综合色阶、纹理密度和统一光源。
```

## 固定禁止漂移段落

把下面一段与正向段落同时加入提示：

```text
不要纯赛璐璐动画上色，不要只有单层硬阴影的扁平动漫图；不要无描线半厚涂、油画厚涂或现代手游宣传画；不要照片写实、电影概念艺术、3D、CGI、PBR、ZBrush雕塑感、塑料或树脂手办质感、平滑全局光照、景深和镜头炫光；不要现代萌系、幼态脸、统一网红脸、矢量图、等粗线、波普网点。不要纸张泛黄、扫描噪点、印刷网点、折痕、套色偏移、卡框、文字、标题或水印。
```

## 批量风格锚点

试生产的三个样例获批后，选择其中最能代表上述规则、且人物和服装没有大面积遮挡的一张批准版设定表作为 `style_anchor_reference`。后续每个角色同时引用：

1. 当前角色原卡，负责身份、造型、配色和可见细节。
2. 批准版风格锚点，**只**负责描线、上色、纹理密度、光源和版式完成度。

提示中必须明确禁止从风格锚点复制脸、服装、配件、纹样、武器、体型或颜色。若风格锚点与当前原卡的角色设计冲突，当前原卡优先。旧项目没有 `generation.style_profile` 时，按本默认档案补录；不要因此重建已经批准的图片。

## 画风验收

以下条件全部满足才算通过：

- 缩略查看时有明确的深色手绘轮廓和综合色块层级；放大后能看到克制的刷痕、排线或材质纹理。
- 同一角色六个全身视角及四个头部视角的线宽、阴影档数、综合色彩、纹理密度和光源一致。
- 画面既不是只有平涂加一层硬阴影的纯赛璐璐，也没有变成边缘消失、依靠连续渐变塑形的半厚涂。
- 皮肤没有照片毛孔或三维蜡感；金属没有 PBR 镜面和环境反射；布料没有三维布料模拟感。
- 脸部保留原卡角色的年龄、骨相和个体差异，没有现代动漫幼态化或批量同脸。
- 设定表背景干净，不残留原卡叙事场景、特效、文字、印刷老化或卡框。
