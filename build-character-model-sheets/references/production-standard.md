# 角色设定表生产标准

## 证据等级

| 等级 | 定义 | 处理方式 |
|---|---|---|
| `confirmed` | 原图中清楚可见，或多张可信来源互相印证 | 精确保留形状、色彩、位置和比例 |
| `inferred` | 为完成转面所必需，能从结构、对称或连接关系合理推出 | 采用克制设计，并明确记录推断 |
| `unknown` | 被遮挡、裁切、过度模糊或存在多种同样合理的解释 | 不宣称确定；采用易修改方案或请求确认 |

文字史料可以帮助理解物件类别，但不得覆盖用户提供原画中的具体视觉设计。

## 实体拆分规则

为满足以下任一条件的对象创建独立设定表：

- 需要独立建模、绑定或动画。
- 会被拿起、收纳、拆卸、变形或频繁出镜。
- 形制复杂，放在人物六视图中无法清楚辨认。
- 是人物身份的重要标志。

小型一次性道具可以保留在人物表中。多个同类简单投掷物可在一张武器表中排列；多个复杂主武器应分表。

## 人物六视图

- 严格按基于左面逆时针转 45 度、左面、正面、背面、右面、基于右面顺时针转 45 度的顺序排列。
- 左、右以角色自身方向为准。第一列和第六列必须使用相对侧面基准的完整名称，不得换算成旧的独立角度编号。
- 保持相同头顶线、脚底线、身体尺度和中立站姿。
- 双臂略离身体，手掌自然，不遮挡腰部和侧缝。
- 左面与右面必须为相反的纯侧视；正面与背面必须为相反的纯正视和纯背视。
- 第一列必须由左面逆时针旋转 45 度得到；第六列必须由右面顺时针旋转 45 度得到。
- 背面必须展示发型后部、衣领、腰带闭合、衣摆和鞋后结构。
- 不用动作姿势、强透视、戏剧光影或场景背景替代结构展示。

### 两个相对 45 度视角的几何门槛

| 视图 | 唯一基准 | 必须执行的旋转 |
|---|---|---|
| 第一列：基于左面逆时针转 45 度 | 第二列左面 | 整个人物绕竖直轴逆时针旋转 45 度 |
| 第六列：基于右面顺时针转 45 度 | 第五列右面 | 整个人物绕竖直轴顺时针旋转 45 度 |

- 两列必须拥有相反的近侧脸颊、耳朵、肩膀、胸甲透视和远侧肢体遮挡。
- 头、胸腔、骨盆、膝盖和双脚必须保持同一偏航角；只改变头部或眼神不算不同视角。
- 两列不得退化为左面、右面或正面，不得互相复制，也不得由水平翻转生成；非对称结构必须保留真实三维锚点。
- 若两列近侧相同、轮廓近似重复，或任一列近似纯侧面或正面，直接拒收并只返修错误列。

## 原画姿态版六视图（可选变体）

原画姿态版用于用户明确要求保留原图动作、服装动态、武器/道具、坐骑、宠物或交互关系的情况。它是默认中立结构版的补充，不替代默认输出。

### 输出保护与证据优先级

- 默认中立结构版保持为 `character-turnaround.png`；原画姿态版默认写入 `character-turnaround-original-pose.png`。除非用户明确要求替换，不得覆盖或改名默认输出。
- 原画负责确认姿态、手势、视线、服装动态、抓握、骑乘和宠物关系；中立六视图只补充被遮挡的侧面/背面结构；已确认头部表只补充身份、头饰与头颈比例。
- 参考图冲突时按“原画可见事实 > 已确认局部表 > 中立六视图的结构性推断”处理。不得用中立六视图的空手、直立姿态覆盖原画动作。
- 原图看不见的背面服装、道具背面、鞍具固定件和宠物远侧结构继续标记为 `inferred` 或 `unknown`。

### 冻结三维组合体

生成前把以下内容写成角色自身坐标系中的一个冻结组合体：

- 头、视线、胸腔、骨盆和重心；左右肩、肘、腕、手指、髋、膝、踝及脚掌接地。
- 手势、抓握点、武器/道具长度与身体相对路径，以及收纳、牵引或缠绕关系。
- 迎风衣袖、披帛、衣摆、头发、尾巴、翅膀等动态轮廓及其根部连接点。
- 骑乘时人物、坐骑、鞍具、缰绳、腿部夹持和手部牵引的接触关系。
- 宠物与人物有明确互动或接触时的位置、朝向、尺度、遮挡和接触点。

六列只改变相机方向；人物、衣物、武器、坐骑、宠物及所有接触点共同绕竖直轴旋转。不得逐列重新摆姿、改变重心、换手、改变握持点、重算风向、移动宠物或重做骑乘姿势。表情变化不能代替视角变化。

### 实体与场景边界

- 原画中由人物持握、穿戴、骑乘、牵引、倚靠或持续互动的对象属于冻结组合体；同时仍可按实体拆分规则生成独立设定表。
- 雷电、岩石、烟雾、云层、题字牌、画框、地面文字和纯叙事背景默认不进入六视图，除非用户明确把它指定为角色效果或可建模实体。
- 一个连续武器或道具必须始终是同一件物体；不得跨视角断裂、复制、变成另一类别或漂离抓握点。
- 没有坐骑或宠物证据时保持 `absent`，不得为填充构图添加。

### 几何与构图门槛

- 仍使用固定六视图顺序及两个相对 45 度视角的几何门槛；头、胸腔、骨盆、膝、脚、抬起的肢体、衣物动态和实体都必须共享同一偏航角。
- 正面应最接近原画的可见动作关系；背面、左右侧面和两个相对 45 度视图必须是同一冻结动作的真实转面，不是六张相似动作插画。
- 六列保持同一人物尺度和地面基准。动作、长兵器、坐骑或宠物扩大轮廓时缩小整套组合体并增加画布留白，不得裁切任何肢体、衣摆或实体端点，也不得让相邻列重叠。
- 若任一列换手、改变腿部前后关系、改变衣物飘向、缺少/复制实体、移动接触点，或第一列与第六列使用同一近侧，直接拒收。

### 规格记录

在 `generation.variants` 中为每个原画姿态版建立记录；`output` 相对当前角色目录：

```json
{
  "id": "original-pose-turnaround",
  "kind": "original-pose-turnaround",
  "status": "planned",
  "output": "character-turnaround-original-pose.png",
  "purpose": "保留原画动作和实体关系的独立六视图",
  "views": [
    "left-profile-counterclockwise-45-degree",
    "left-profile",
    "front",
    "back",
    "right-profile",
    "right-profile-clockwise-45-degree"
  ],
  "pose": "角色自身坐标系中的冻结姿态",
  "costume_motion": "冻结衣物、头发或尾部动态及根部连接",
  "entity_relations": "武器、坐骑、宠物的抓握与接触关系",
  "background": "plain light neutral"
}
```

状态可为 `planned`、`generated` 或 `approved`。生成文件后更新状态；批准原画姿态版不自动批准默认中立版，反之亦然。

## 头部放大视图

- 每张人物设定表固定包含四张等比例头肩裁切放大图，顺序为：正面、背面、左侧面、右侧面。
- 左、右以角色自身方向为准，并与全身视图以及 `character.asymmetric_anchors` 使用相同的解剖侧定义。
- 四张保持同一脸型、颅骨体积、五官比例、发际线、发型、胡须、耳朵、头饰锚点、颈部尺度、中立表情、光照和裁切范围。
- 左侧面与右侧面必须来自角色不同侧，不得复制或水平翻转；纯背面必须完整展示后脑发型和头饰连接结构。
- 后脑结构不可见时遵守证据等级：只把原图可见内容记为 `confirmed`，克制补全记为 `inferred`，无法判定项记为 `unknown`。
- 表情变化不能代替转面。只有用户要求表情表时才另行生成，并保持已批准的头部结构不变。

## 非对称特征锚点

在 `character.asymmetric_anchors` 中为每个左右不对称特征建立独立记录：

```json
{
  "feature": "放射状金色头饰",
  "anatomical_side": "character-left",
  "attachment_point": "left-rear-crown",
  "local_orientation": "radially backward and outward",
  "never_mirror": true,
  "never_reposition_for_visibility": true,
  "visibility_by_view": {
    "left-profile-counterclockwise-45-degree": "近侧，按左面逆时针旋转后的真实投影显示",
    "left-profile": "近侧，完整或大部分可见",
    "front": "画面右侧可见",
    "back": "画面左侧可见",
    "right-profile": "远侧，被头部和帽冠部分遮挡",
    "right-profile-clockwise-45-degree": "远侧，按右面顺时针旋转后的真实投影显示"
  }
}
```

- `anatomical_side` 始终表示角色自身的左、右或中线，不表示画面左、右。
- `attachment_point` 描述具体三维连接位置；使用“左后冠”“右肩后部”等位置，不只写“左边”。
- `local_orientation` 描述特征相对连接点的固定朝向、展开方向和倾角。
- 旋转六视图时只改变观察角度，不改变锚点、朝向、数量、间距或展开形状。
- 允许投影位置随视角变化；不允许换边、镜像、复制，或为了保持完整可见而重新连接到近侧。
- 远侧特征遵守真实遮挡。角色自身左侧特征通常在“基于左面逆时针转 45 度”与“左面”为近侧，在“右面”与“基于右面顺时针转 45 度”为远侧；右侧特征反之。
- 成对检查正面/背面、左面/右面、两个相对 45 度视图。若位置与完整可见性冲突，优先保持三维锚点和真实遮挡。

## 武器表

至少展示：完整轮廓、正反面、最薄侧面、握持点、收纳或连接状态、与人物的比例。复杂机械或组合兵器再展示拆件、展开和闭合状态。

## 坐骑与宠物表

坐骑与宠物默认使用相同六视图，并增加人物并排比例；坐骑还要展示骑乘接触关系。翅膀、尾巴、角、鞍具、缰绳和甲具存在不同状态时分别展示。

## 批量一致性

- 先批准一张项目基准表，锁定纸张比例、背景、线条密度、着色方式和留白。
- 每个角色先批准角色规格，再生成图像。
- 同一角色返修时引用已批准基准图，不从头重新解释设计。
- 不为追求整齐而统一不同人物本来不同的体型、年龄感或服装结构。

## 交付验收

人物表必须满足：身份一致、六视图齐全、按正面、背面、左侧面、右侧面排列的头部四视图放大齐全、无裁切、无非预期遮挡、无结构矛盾、无意外镜像；两个相对 45 度视图通过几何门槛，所有非对称特征保持同一解剖侧和三维锚点。原画姿态版还必须保持同一冻结姿态、服装动态、实体及接触关系，且不覆盖默认中立版。实体表必须满足：比例可信、连接关系明确、没有与人物表冲突。所有推断均应能在 `character-spec.json` 中追溯。
